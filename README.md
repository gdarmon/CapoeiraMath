# Darmon Capoeira

משחק PWA קטן לאנדרויד ולווב לתרגול לוח הכפל, פעולות חשבון עד מיליון, שברים ועשרוניים דרך קפוארה, קצב ותשובות בלחיצה.

## הפעלה מקומית

```bash
cd /localdrive/users/giladdar/CapoeiraMath
npm start
```

פתחו בדפדפן:

```text
http://localhost:4173
```

## התקנה באנדרויד

כדי להתקין על הטלפון, צריך לפתוח את האפליקציה ב-Chrome מכתובת HTTPS, או להגיש אותה משרת מקומי עם תעודה. אחרי שהדף נטען:

1. פותחים את תפריט Chrome.
2. בוחרים `Install app` או `Add to Home screen`.
3. האפליקציה תמשיך לעבוד גם ללא אינטרנט אחרי הטעינה הראשונה.

## מה יש במשחק

- רודה מלאה של 18 שאלות ומסלול מהיר של 15 שאלות.
- לוח הכפל 1-10, בוסים, פעולות חשבון, שברים ועשרוניים.
- הפרדה מלאה בין המסלולים: ברודה המלאה פותחים חגורות, ובמסלול המהיר פותחים כלי נגינה עם מונה חותמות עצמאי לכל כלי.
- במסלול הרגיל, כל תשובה נכונה מלמדת מחמאה או ביטוי קצר בפורטוגזית ומסבירה את משמעותו בעברית.
- ההתקדמות נשמרת בגיבוי מקומי ובגיבוי Android נפרד, כולל חגורה, כלי נגינה והמורים שכבר נפתחו.
- כאשר קיימת גרסה חדשה מופיע בסרגל העליון סמל עדכון: עדכון PWA במחשב או עדכון מיידי דרך Google Play ב־Android.
- אין הקלדה: רק כפתורי תשובה גדולים.
- חזרה חכמה על טעויות.
- אנימציית קפוארה, צלילי קצב, רטט והקראה בעברית.
- שמירת התקדמות מקומית במכשיר.
